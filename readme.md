# 📊 **Derivable Judgement: A Statistical Decision-Making Model**

## 📋 **Project Overview**  
You are hired as a data analyst at a public health research organization. You have been given a dataset containing health records of individuals, including lifestyle habits (smoking, exercise), age groups, and diseases (e.g., Diabetes, Hypertension). Your task is to use **inferential statistics** to **derive judgments** about the significant factors affecting disease occurrence based on various tests (z-test, t-test, chi-square, ANOVA), correlation, and covariance. 📊💉

---

## 🔧 **Technologies Used**  
- Python (NumPy, Pandas, SciPy, Statsmodels) 🐍  
- Jupyter Notebook / Excel 📓💻  
- Statistical Analysis (Hypothesis Testing, Confidence Intervals, z-test, t-test, ANOVA, etc.) 📈

---

## 🧑‍💻 **Project Structure**

### 📥 **Dataset Information**  
The dataset should contain the following fields:

- **record_id**: Unique identifier for each health record 🔢  
- **age_group**: Age group category (e.g., "18-25", "26-35", "36-45", "46-60", "60+") 👶👵  
- **age**: Age of individuals 🎂  
- **weight**: Weight of individual ⚖️  
- **gender**: Gender of the individual (Male, Female, Other) 👨👩  
- **region**: Geographic region (e.g., "North", "South", "East", "West") 🌍  
- **smoking_status**: Smoking habit (Smoker, Non-Smoker, Former Smoker) 🚬  
- **exercise_frequency**: Frequency of physical exercise (Daily, Weekly, Rarely, Never) 🏃  
- **bmi**: Body Mass Index (BMI) 🏋️‍♀️  
- **blood_pressure**: Measured systolic blood pressure (mmHg) 💓  
- **diabetes**: Whether the individual has diabetes (True/False) 🩸  
- **hypertension**: Whether the individual has hypertension (True/False) 💊  
- **cholesterol_level**: Total cholesterol level (mg/dL) 🧴  
- **glucose_level**: Fasting glucose level (mg/dL) 🍬  
- **visit_date**: Date of health check-up or diagnosis 📅

## 📑 **Task List**

### **Part A: Theoretical Foundation**
1. **What is inferential statistics?** 📉  
2. **What is hypothesis testing and its components?** 💭  
3. **Explain confidence interval and critical value.** 🔢  
4. **Define p-value.** 📊  
5. **Differentiate Type I and Type II errors.** ⚖️  
6. **Brief descriptions of z-test, t-test, chi-square test, and ANOVA test.** 🧮  
7. **What is Correlation?** 🔗

### **Part B: Data Analysis & Testing Tasks**
1. **Formulate at least two hypotheses** from the dataset (e.g., Smoking affects Diabetes prevalence). 📝  
2. **Calculate Confidence Intervals** for key numerical data (e.g., age, weight). 📊  
3. **Find the Critical Value and p-value** to interpret test results. 🔑  
4. **Perform z-test or t-test** based on sample size (mean comparison across groups). 🔬  
5. **Conduct a chi-square test** on categorical data (e.g., Smoking habit vs Disease). 🎲  
6. **Perform an ANOVA test** to check if age groups significantly differ in disease rate. 📅  
7. **Calculate Covariance and Correlation** between continuous variables (e.g., Age vs BMI). 🔄  
8. **State the result and interpretation** (Accept/Reject Ho) of each test performed. ✅❌
